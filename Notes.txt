# School Management System API Documentation

## Postman Environment Setup

1. Create a new environment in Postman named "School Management System"
2. Add the following variables:
   - `base_url`: http://localhost:8080 (or your server port)
   - `token`: (leave empty initially, will be set after login)

## API Endpoints

### Authentication

#### Login
- **URL**: {{base_url}}/api/auth/login
- **Method**: POST
- **Body** (JSON):
```json
{
    "username": "admin",
    "password": "password123"
}
```
- **Response**: Contains JWT token that should be saved to the `token` environment variable

#### Register
- **URL**: {{base_url}}/api/auth/register
- **Method**: POST
- **Body** (JSON):
```json
{
    "username": "newuser",
    "password": "password123",
    "email": "user@example.com",
    "role": "USER"
}
```

#### Logout
- **URL**: {{base_url}}/api/auth/logout
- **Method**: POST
- **Headers**: Authorization: Bearer {{token}}

### Students

#### Get All Students
- **URL**: {{base_url}}/api/protected/students
- **Method**: GET
- **Headers**: Authorization: Bearer {{token}}

#### Get Student by ID
- **URL**: {{base_url}}/api/protected/students/{id}
- **Method**: GET
- **Headers**: Authorization: Bearer {{token}}

#### Count Students
- **URL**: {{base_url}}/api/protected/students/count
- **Method**: GET
- **Headers**: Authorization: Bearer {{token}}

#### Count Students by Grade
- **URL**: {{base_url}}/api/protected/students/count/grade/{gradeId}
- **Method**: GET
- **Headers**: Authorization: Bearer {{token}}

#### Count Students by Class
- **URL**: {{base_url}}/api/protected/students/count/class/{classId}
- **Method**: GET
- **Headers**: Authorization: Bearer {{token}}

#### Create Student
- **URL**: {{base_url}}/api/protected/students
- **Method**: POST
- **Headers**: Authorization: Bearer {{token}}
- **Body** (JSON):
```json
{
    "firstName": "John",
    "lastName": "Doe",
    "dateOfBirth": "2010-01-01",
    "gender": "Male",
    "address": "123 Main St",
    "gradeId": 1,
    "className": "Class A"
}
```

#### Update Student
- **URL**: {{base_url}}/api/protected/students/{id}
- **Method**: PUT
- **Headers**: Authorization: Bearer {{token}}
- **Body** (JSON):
```json
{
    "firstName": "John",

    "gender": "Male",
```

#### Delete Student
- **URL**: {{base_url}}/api/protected/students/{id}
- **Method**: DELETE
- **Headers**: Authorization: Bearer {{token}}

## Testing Workflow

1. Register a new user or login with existing credentials
2. Save the returned token to the Postman environment
3. Use the token for subsequent API calls
4. Test each endpoint with valid and invalid data
5. Verify response status codes and data

## Common HTTP Status Codes

- 200 OK: Request successful
- 201 Created: Resource created successfully
- 400 Bad Request: Invalid input
- 401 Unauthorized: Missing or invalid authentication
- 403 Forbidden: Not enough permissions
- 404 Not Found: Resource not found
- 500 Internal Server Error: Server-side error
